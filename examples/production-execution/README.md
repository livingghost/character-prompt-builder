# Executable production examples

Run from the Skill root, choosing a new output directory for each example:

```text
python examples/production-execution/run_example.py --out EXAMPLE_OUTPUT
python examples/production-execution/repair_example.py --out REPAIR_OUTPUT
python examples/story-context/run_example.py --out MOMENT_OUTPUT
```

The first example runs the complete text delivery through the CLI. The second creates an actual
synthetic PNG, records a failed located image check, chooses a specific repair, authorizes the
exact revised preparation, captures a new PNG, reviews and selects it, and finishes the linked
work task. The third retains the bounded story-moment query and its private/public distinction.
Each output includes `commands.json`, input authority and its synthetic evidence, intent and
request files, complete production receipts, actual results and a final result summary.

All authority is conspicuously synthetic and exists only for executable fixtures. No production
command invents missing approvals. No network calls, purchased generation, audience assessment,
character performance or finished-artwork quality is claimed. The fixtures test processing,
operation boundaries and lifecycle connection. They are not a genre template or a prescribed
way to express a character.
