# Executable production examples

Run from the Skill root, choosing a new output directory for each example:

```text
python examples/production-execution/run_example.py --out EXAMPLE_OUTPUT
python examples/production-execution/repair_example.py --out REPAIR_OUTPUT
python examples/story-context/run_example.py --out MOMENT_OUTPUT
```

The first example saves an authored text revision through the CLI, delivers those exact bytes
to a local file, records its separate evidence-backed review, and finishes the owning work
task. It does not create an external-generation candidate or a human
acknowledgement. The second sends an exact input to a local synthetic raster host under an
external execution claim and records its actual call, PNG and response. After a failed located
image check it chooses a specific repair, authorizes the exact revised preparation, receives a
new PNG from that host, reviews and selects it, and finishes the linked work task. The third
retains the bounded story-moment query and its private/public distinction, and records
an actual captured output-stream presentation of its saved text before review.
Each output includes `commands.json`, its actual authored or execution records, the retained
result and a final summary. Examples that exercise external operations also retain their
synthetic authority, exact input, claim and result receipts.

All authority is conspicuously synthetic and exists only for executable fixtures. No production
command invents missing approvals. No network calls, purchased generation, audience assessment,
character performance or finished-artwork quality is claimed. The fixtures test processing,
operation boundaries and lifecycle connection. They are not a genre template or a prescribed
way to express a character.

[Evidence review cases](evidence-review-cases.md) give neutral, authored cases
for competing prompt realizations, artifact-first observation, inconclusive
evidence and valid alternative compositions. Their hypothetical observations
illustrate review decisions; they are not generated-image measurements.
