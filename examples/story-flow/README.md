# Automatic story reading example

```bash
python examples/story-flow/build_example.py --out /path/to/new-story-demo
```

Open `timeline.html` at the Studio root. Flow discovers the ordinary narrative and scene files.
The example has an accusation, separate approaches and an unexplained act of trust.
All state records are structurally consistent; the reader decides whether the story
needs another scene, a stated motive or an intentional later reveal.

Pin the first passage and open the last. Read the two accounts side by side.
Switch to story order, inspect related events, or use Axis to see exact resolver values.
The page creates no new approval and no generated image.

The example is synthetic, with no personal pack or service call.
See [Story Flow](../../references/runtime/story-timeline.md) for the current contract.
