# Common runtime sequence

Apply the steps required by the image deliverable:

1. Resolve the artifact. For saved work, establish the Studio and read its route.
2. Set the artifact's scope and current situation. Separate requirements, open expression and incidental deductions. Consult knowledge before selecting presentation, hierarchy and relationships. For character reuse, resolve reference coverage and stage targets.
3. Read interface guidance; resolve the optional `prompt-writing-guide` and read the complete selected guide before final rendition. Retrieve the chosen construction's visual elements. Inspect every selected canonical record in full. Resolve the dispatcher execution profile.
4. Build the wanted picture: necessary situation, hierarchy and local views, identity, state, action, finish and reference roles. Supply premises before dependent cues. Establish qualities and degree, then select exclusions for this depiction and input use. Combine sources by meaning.
5. Reconstruct the picture from delivered text, negatives, controls and media. Compare it with the scoped brief: find missing premises, changed meaning and added tasks. Check qualities, degree, action, visibility and reference roles. Resolve conflicts within authority; ask about irreconcilable requirements and keep them open. Recheck omissions, emphasis, repetition and leakage after changes. Keep review in its record; retain plot approval and settle retrieval against final wording.
6. Save prompt, settings, evidence and any Studio destination in the task's declared inputs.
7. `production_workflow.py check --task task.json` reports diagnostics without creating a run. `prepare` publishes request preview, execution plan and any dispatcher Generation Package.
8. Review the complete prepared request and operation targets, repeating step 5 after transport changes. Dispatcher work follows `draft-execution`, actual decisions and `execute`.
9. External work follows handoff, exact authorization, `claim-external`, host call, `capture` and `settle-external`. After interruption, `resume` recovers the existing execution.
10. Compare candidates with the same requirements and selected expression; diagnose failures from evidence. Dispatcher trials use `variant`, `repeat` or `retarget`; external trials use new tasks and exact input binding. Edits need semantic plans.
11. `status` reports runs, next commands and execution records. [Operation logs](operation-logs.md) owns inspection, export and cleanup. Inspect staging before cleanup of its exact owner operation.

Production Execution defines these commands, each with `--root STUDIO`. Prose and conversation-only prompts need no generation workflow.
