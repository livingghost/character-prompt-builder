# Revision contract

Use this contract when a request changes an actual candidate. Develop the
requested result through [Production direction](production-direction.md), and
perform the change through [Authoring work](authoring-work.md). The author
judges the scope and meaning. The runtime compares the candidate's actual
content and checks its acquired source bindings.

## Select the operation from the request

Read the current request and applicable adopted requirements. Establish what
must remain and which choices the request permits reconsidering. A supplied
prompt is a concrete proposal; its presence alone does not give every staging
choice permanent authority. A scoped amendment retains the selected baseline
outside the authorized changes and their necessary consequences. Composition
builds the current candidate from the request and source applications. Both
operations preserve the character definition and other adopted requirements
within their actual scopes.

Choose the operation from the relationships being kept or reconsidered. A
small textual change can redirect the picture's organizing idea; a substantial
rewrite can preserve the same construction for another interface. The name of
a property, a count of edited fields or an emotion label does not determine
that judgment. Resolve the open choices within delegation. When a fixed
requirement conflicts with the requested result, seek only the necessary
owner decision.

An assessment or repair recommendation is evidence for a decision. Apply an
edit when the request or existing authority commissions it. A correction to
the reasoning behind a review calls for reassessment of that reasoning.

## Inspect the actual candidate

Authoring work retains the current request, actual candidate, source uses and
its baseline where applicable. Run the inspection against that work:

```bash
python scripts/revision_contract.py WORK --out REPORT
```

Read the derived difference and unresolved source-binding findings. The
comparison uses the actual authored content. Fix an issue at its owning
candidate or source application, then inspect the work again. A report locates
the change and its declared scope; the author evaluates whether the new
construction serves the request and whether its wording carries the intended
meaning.

Use the exact `edit` or `replace-text` operation for a bounded correction. It
changes the selected actual value or text and preserves the surrounding content.
Review the derived difference against the scope the request authorizes. Follow
the consequences of a chosen change through the same
construction. Keep the applicable identity, source allowances and criteria
available to the new candidate and its review. An identity change requires
that owner's actual authority. Keeping a provisional choice during an
amendment gives it no additional canonical status.

For a target conversion, preserve the requested meaning while choosing the
new interface's supported wording and controls. A target limitation that
changes required meaning needs the authorial decision that would authorize
that change. Selected source images keep their assigned subjects, properties
and limits through [Reference Delivery](reference-delivery.md).

## Read and deliver the result

Describe the corrected appearance, action, relationship or degree and its
necessary premises. Use [Select the depiction](prompt-composition.md#select-the-depiction)
to construct the picture and perform its complete-input readback. Carry the
character's relevant concrete definition and researched wording into the
actual input. Keep the full definition available for review even when the
chosen frame shows only part of the character.

Judge the complete candidate against the current request, the retained
requirements and permitted variation. Observe whether the selected construction
provides the intended experience. A mechanically valid change establishes no
rendered success; a textual review establishes no observation of an ungenerated
image. Return the complete current prompt, applicable negative and selected
reference deliverables. Return a diff when requested.

## Saved work and completion

Save or prepare this candidate through [Production authoring](production-authoring.md).
The Studio adapter uses the same authoring work and retains its actual request
and source evidence. [Authored storage](production-authored-storage.md) records
the exact revision, delivery and review that were commissioned. Model execution
prepares its exact input, captures the actual result and binds review and
selection to that result. Canonical adoption records its own decision and
destination.

Use the current status and continuation actions to locate unresolved work.
Complete the operation that was requested, keeping previous revisions and their
observations available. A saved revision, generated image, selected candidate
and canonical adoption each establish their own result.
