# Observed Realization, Repair and State Write-back

A generated image, sentence, performance or sound is evidence of an output, not
new canonical world state. Keep expected facts, authorial intent, actual
observations and adopted changes separate.
[Scoped Realization](runtime/world-realization.md) owns the coordinating
workflow and [Authorial Intent](runtime/authorial-intent.md) owns the depiction
criteria.

## Observation chain

```text
pinned world/persona/intent sources and expected state
+ applicable projection and bounded reference evidence
+ exact submitted input
+ actual inspected output and locator
-> observation, with uncertainty
-> discrepancy or supported intentional departure
-> owning layer and smallest justified correction
-> compared candidates and explicit creator decision
```

For rendered state use the existing `observed-render-state` and, where needed,
`drift-observation` artifacts. Observed output stays `canonized: false`. For
other media use the
[realization review form](../templates/realization/review-template.md), a
worksheet, not a new typed shared-state artifact. Author-facing diagnosis is
not automatically a safe consumer view.

## Diagnose the owner, not a convenient downstream symptom

| Finding | First owner to review |
|---|---|
| Source interpreted incorrectly, aliases conflated or an assumption treated as fact | Source/world design and provenance |
| Wrong scene, timeline, order, event consequence or current knowledge | State target, ledger/process and epistemic owner |
| Correct world but wrong fact selected or an essential constraint omitted | Scene context and projection |
| Candidate reference lacks a required feature or owns an unrelated source state | Reference selection, bounded use and adoption |
| Correct physical state but wrong voice, bearing, cadence or accumulated identity | Persona/authorial intent and actual performance |
| Correct instructions but observed geometry, timing or surface defects | Targeted generation correction, with real evidence |
| A deliberate cut, omission, contrast, rupture or unresolved account is being flattened | Scoped authorial intent and review criteria |
| An author-only or future fact appears in a recipient's input or output | Consumer selection and information access |
| A canonical fact truly should change | Explicit creator decision, then the authoritative record |

These routes can overlap. Record what is known and what is unknown, and leave
the generator's internal cause unguessed. A local mismatch can originate
upstream; changing an identity contract to fit a bad render only makes the
error consistent.

## Correct and select

Name the expected constraint, observed deviation, evidence locator, affected
span, smallest proposed correction and retained dimensions. Inspect previous
and revised candidates under the same current inputs and criteria. Keep the
previous candidate unless the revision is demonstrably better within the chosen
criteria, and record unresolved tradeoffs for the creator. Set a bounded retry
plan appropriate to the task rather than copying a paper's iteration count.

Judge against the adopted intention, not an aggregate score. A stylized
movement or abrupt cut can be deliberate, and smoothness is one aim among
others. Equally, an after-the-fact creative exception leaves an accidental
mismatch accidental; a newly interesting accident can be proposed honestly and
then adopted with its own scope.

## Update only the owning authority

A human-approved observation or accepted visible story event may justify an
approved State Event; observation alone leaves the ledger unchanged. An
editorial redesign may instead change a design/world record and require
recomputation while staying outside the characters' knowledge. Stable visual
geometry, an era/form transition, temporary physical state and one realization
have distinct owners, so a local change reaches other phases or timelines only
by an explicit decision.

For declared structures, separate a profile/attachment/count error, an
individual marking or measurement error, a changed injury/form and an
occlusion/crop problem, and correct the specific owner. A covered part is still
present, and a species label leaves anatomy undeclared.

Run source-impact review, rebuild applicable states and consumer views,
reselect references when needed, and inspect affected actual outputs. The
realization helper reports conservative source impact; canon and existing JSON
approvals stay as they were. Keep the exact previous inputs and evidence so the
choice and its consequences remain traceable.


Record exact candidates, observations and selections through
[Production Execution](runtime/production-execution.md). Keep writeback under
the owning state or adoption contract; the production receipt leaves writeback
to that owner.
