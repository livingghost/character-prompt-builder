# Prompt Composition Geometry

## Conditional catalog examples

Every literal catalog ID in this document is actionable only when its owning pack is present, enabled by the selected state, and the exact ID resolves in the active catalog. If an example ID is absent, apply the complete geometry rule directly, search enabled records for genuinely matching knowledge, or proceed without preset support. Never substitute an unrelated ID or assume that an external-pack example belongs to the default pack.

This reference belongs to the normal runtime workflow. It applies whenever the agent composes or revises a model-facing prompt, not only when contributors author catalog records. It preserves the full production knowledge behind prompt economy, overlap order, organic distributions, camera consequences, species authority, and related-variant ownership.

## 1. Prompt economy preserves canonical records

Every sentence in a model-facing prompt is a vote. A prompt that grows by patch accretion weakens each instruction it contains, and late guards begin to fight earlier ones.

Prompt economy applies to the emitted model-facing projection:

- keep one clause for each contract-supported or scope-documented failure mechanism
- remove a counterweight after its cause has been removed
- repeat only instructions observed as fragile within the documented evidence scope, near the clauses they control
- when a removed axis regresses, restore that one clause instead of the whole previous prompt
- after changing a species, build, style, or camera scaffold, remove counter-text that existed only to fight the old scaffold

Prompt economy does not authorize summary damage to the catalog. Canonical curated records retain their complete image intent, structured geometry, invariants, adaptation rules, evidence scope, diagnostics, and failure knowledge. A shorter emitted prompt is a projection of that complete record, never a replacement for it.

## 2. Scaffold changes require counter-text cleanup

Counter-text calibrated against the wrong prior becomes over-correction under the right one. A phrase that held a canine scaffold at a short deep muzzle can push a feline scaffold into a round bear-like face after the species prior changes.

After changing a scaffold:

1. list the clauses that existed to counter the previous prior
2. remove those clauses from the next candidate prompt
3. retain only the smallest affirmative floor still required by the target design (for example, a clear forward projection)
4. compare the new output before adding further repair language

## 3. Spatial relations use three independent codes

Side words alone do not reliably hold front-to-back order. State every critical overlap in three independent ways:

1. anatomical or image-space side from both directions
2. a unique visible marker carried by the front element
3. explicit occlusion verbs

Example:

- the left forearm crosses in front of the torso
- the bracelet-bearing forearm is the front arm
- it covers the upper edge of the right forearm, whose hand remains visible below

The reverse relation must also be recoverable: the right forearm passes behind the bracelet-bearing left forearm. The marker can be a bracelet, sleeve, glove, scar, color patch, prop, or any other stable distinguishing feature.

Use the same method for crossed legs, layered tails, straps, wings, garments, props, and multi-character contact. The reference attribute audit in `references/preset-authoring-standard.md` supplies the sides and markers.

## 4. Organic variation is a distribution

Write organic variety as a distribution instead of a list of fixed coordinates. A robust distribution contains:

- a count or count range
- a size anchored to a local landmark
- a local directional rule
- an irregularity rule
- a spacing or overlap rule

Example for mane lobes:

- five to eight principal lobes
- the largest neck lobe is about the length of the muzzle
- each lobe follows the local curve of the mass it grows from
- directions vary with the local curve
- nothing is combed into one shared direction
- overlaps occur at irregular intervals

This survives pose changes. Enumerated screen positions invite uniform repetition and break when the camera or body turns.

## 5. Camera terms become visible consequences

A camera label alone often fails to move the frame. State the move as visible evidence:

- give a magnitude or bounded range when useful
- name the environmental lines or scale relationships that change
- name the subject geometry that stays stable
- keep the consequence coherent through foreground, middle ground, and background

For a Dutch angle, state the roll through the floor line, horizon, window frames, door frames, shelves, or other architectural verticals, so those lines run visibly diagonal and the figure occupies a diagonal frame. Keep the subject spine, stance, and local anatomy coherent inside the rolled frame. In short: consequence, magnitude, subject lock.

## 6. Species identity outranks scaffold heuristics

A species noun is both an identity statement and a geometry vote. Every occurrence can re-summon default proportions from the model prior.

Use this authority order:

1. explicit user species anchor
2. approved Character Identity Contract
3. species-neutral geometry wording
4. the named species scaffold already consistent with the identity
5. a different species noun only as a disclosed modification approved for the task

A scaffold heuristic never silently changes a wolf into a feline, a canine into a bear, or any other explicit identity. When the nominal identity and observed facial geometry differ, first describe the geometry directly: ear shape, ear set, ear orientation, muzzle reach, muzzle depth, nose proportions, jaw mass, cheek volume, and eye placement.

`references/species-architecture.md` is a prompt-prior scaffold reference, not a complete biological taxonomy. When the selected pack state provides `cpb-resource:species-scaffold-map`, resolve it from the explicitly selected provider and use only the coverage it actually declares. Without a selected provider, no scaffold-map coverage is implied; use direct geometry description.

## 7. Runtime selection of related variants

Records sharing one `discovery_group` represent one discoverable family. Select one production owner for one axis unless the records explicitly describe additive layers.

For a rolled-camera family, discovery may return an umbrella vocabulary record plus magnitude-specific variants. Treat the umbrella as a search route, inspect the records returned by the currently active catalog, and select exactly one production owner for the requested roll magnitude. Do not hard-code a record ID from an optional pack into core prompt logic or examples.

The final model-facing prompt adopts one resolved magnitude-specific camera record, so the roll instruction appears once.

## 8. Review checklist

Before returning the final prompt, verify:

- repeated clauses were merged while their canonical source detail remains intact
- every critical overlap has side, marker, and occlusion evidence
- organic groups use count, scale, direction, irregularity, and spacing rules
- camera labels have visible consequences and stable subject geometry
- user species identity remains unchanged unless a disclosed modification was approved
- each discovery group contributes one production owner for each non-additive axis
