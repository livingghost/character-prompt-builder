# Grok Imagine Adapter

Use this adapter only for an active Grok Imagine model record. Complete [Image Generation Runtime](../runtime/image-generation.md) first.

## Prompt rendition

Read the [Prompt Writing Guide Runtime](../runtime/prompt-writing-guide.md) before final rendition. Use its interface-neutral hierarchy, visible-scope, and controlled-comparison rules, but keep the delivered prompt as supported prose and do not add Stable Diffusion attention syntax, LoRA calls, or embedding tokens.

Use natural-language art direction with explicit relationships, spatial construction, camera consequences, and material behavior. Keep the hierarchy content-first: identity, performance, composition, environment and light, medium and finish, then critical construction. The endpoint accepts one prose field and no negative field.

Grok Imagine uses `integrated-critical` negative transport. Translate the few activated technical requirements into affirmative visible construction in the positive rendition, and retain the complete portable negative in the Generation Package. If the response reports a revised prompt, record it beside the committed prompt; the committed package stays authoritative. When the master exceeds the record's accepted prompt length, compress by the summarization recipe rather than truncating.

Always pin the delivery geometry explicitly from the accepted width and height pairs the active model record lists; with reference images the resolution preset takes the aspect from the first input. A frame whose geometry is left to the surface is reframed by it.

## Reference transport

Use only the reference media declared by the active model record, and no more reference images per request than the record's declared count. State each reference's role in the prompt: what to take from it and what must not carry over. Transport a safe selected SVG as a deterministic PNG derived from that same SVG, retaining source hash, transport hash, renderer identity and release, dimensions, and `max_side`. Never send raw SVG, substitute a nearby evidence artifact, or drop a failed reference and continue with text alone.

## Stop conditions

Stop before packaging when deterministic rasterization, Visual preflight, target media validation, visual authority, plan resolution, or carrier verification fails. A provider refusal is a stop, not a retry surface: do not iterate against it. Do not reconstruct or simplify the committed generation input.
