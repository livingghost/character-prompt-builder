# Instruction-Edit Adapter

## Purpose

Use this adapter for image models that transform supplied images from a natural-language edit instruction. It governs change scope, preservation clauses, identity consistency and edit intent. Resolve transport from the exact model offering, or acquired provider evidence for an external semantic trial. The adapter family implies no media or negative channel.

## Instruction construction

Read the [Prompt Writing Guide Runtime](../runtime/prompt-writing-guide.md) before final rendition. Apply its interface-neutral hierarchy and visible-scope rules to the edit instruction, but do not import Stable Diffusion attention syntax, LoRA calls, embedding tokens, or tag formatting unless the exact active model record supports them.

1. Establish the requested finished result and the affected subject or region in the actual supplied image.
2. State what must remain unchanged, especially permanent identity, body construction, markings, clothing continuity, camera, and background elements outside the change scope.
3. Refine the visible construction and necessary exclusions within that result. Preserve the identity detail the edit depends on.
4. Keep presentation state such as pose, expression, gaze, wind, wetness, and temporary styling outside permanent identity unless the request explicitly fixes it.
5. Respect the exact interface's reference limit, prompt length, supported resolutions, output count and aspect behavior.

## Negative transport

For dispatch, read `negative_transport_mode` from the active model record. For an external trial, inspect the acquired fields and prompt guidance. A single prose channel carries the necessary preservation and exclusion clauses; a documented negative channel may carry the corresponding exclusions. Choose wording for its meaning, including direct negation when needed. Retain the portable negative when authored. Merge only provider-backed recommendations with provenance, and keep the complete requested edit.

## Reference handling

Preserve source order and role. A model-specific reference limit is a hard gate in planning, preparation, packaging, and verification. Do not silently drop an excess reference or substitute another artifact.
