# NovelAI Adapter

Use this adapter only for an active NovelAI model record. Complete [Image Generation Runtime](../runtime/image-generation.md) first.

## Prompt rendition

Read the [Prompt Writing Guide Runtime](../runtime/prompt-writing-guide.md) before final rendition. Apply its interface-neutral hierarchy and prompt-pressure rules. Transpose Stable Diffusion attention syntax only when the active NovelAI interface explicitly supports that exact grammar.

Place well-supported high-priority tags first when useful, then add concise natural-language relationships, identity construction, performance, camera, and scene details. Keep the chosen art direction in the rendition rather than a generic tag stack.

## Negative transport

Use `separate-field`. Send the verified negative prompt to undesired content. Preserve the complete verified text, including the structural and medium-drift terms activated for the current subject and framing.

## Reference forwarding

Use only the reference media and count declared by the active model record. Forward the verifier's prompt, undesired-content field, parameters, and committed carriers exactly. Stop if the active interface is unable to receive the complete plan.
