# NovelAI Adapter

Use this adapter only for an active NovelAI model record. Complete [Image Generation Runtime](../runtime/image-generation.md) first.

Read the selected [model guidance card](../runtime/render-contract.md)
and resolve the version, mode and interface it identifies. The adapter selects
the provider boundary; the active model and offering supply its capabilities.

## Prompt rendition

Read the [Prompt Writing Guide Runtime](../runtime/prompt-writing-guide.md) before
final rendition. Apply its hierarchy and prompt-pressure rules using the selected
model's declared forms, dialect, scoped guidance and native suggestions. Complete
the dictionary search when its input mode requires it. Those records carry the
version-specific vocabulary, controls and attributed provider evidence.

Use only attention syntax supported by the selected interface. Preserve the
intended relationships, identity, performance and scene in the supported form,
keeping the chosen art direction. Keep separate prompt scopes where the active
interface declares them.

## Negative transport

Use the negative transport and field declared by the selected model and offering.
Preserve the complete verified text, including the structural and medium-drift
terms activated for the current subject and framing.

## Reference forwarding

Use only the reference media and count declared by the active model record.
Forward the verifier's prompt, declared negative channel, parameters and committed
carriers exactly. Stop if the active interface is unable to receive the complete
plan.
