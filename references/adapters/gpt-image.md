# GPT Image Adapter

Use this adapter only for an active GPT Image model record. Complete [Image Generation Runtime](../runtime/image-generation.md) first.

## Prompt rendition

Read the [Prompt Writing Guide Runtime](../runtime/prompt-writing-guide.md) before final rendition. Use its interface-neutral hierarchy, visible-scope, and controlled-comparison rules, but keep the delivered prompt natural-language and do not add Stable Diffusion attention syntax.

Use natural-language art direction to establish the complete wanted scene before refining identity, spatial construction and material behavior. Make relationships, performance, camera and finish work together. Preserve the full detail needed for the intended character.

GPT Image uses `integrated-critical` negative transport. Author the needed exclusions within the coherent single-field rendition, using direct negation or positive construction according to their meaning. Retain an authored portable negative in the Generation Package when present. Supply the reviewed integrated prompt, or certify the primary prompt with `--critical-avoidance-integrated` after reviewing the complete input.

## Reference transport

For `gpt-image-2.5-flare`, use only the reference media declared by its active model record. The current record declares PNG, JPEG, and WebP. Preserve a supported raster byte-for-byte after validation.

Transport a safe selected SVG as a deterministic PNG derived from that same SVG. Retain the SVG as authoritative `source`, commit the PNG as `transport`, and preserve source hash, transport hash, renderer identity and release, dimensions, and `max_side`. Never send raw SVG, substitute a nearby evidence artifact, or remove a failed reference and continue with text alone.

Use `multi-image` when the active endpoint accepts every planned reference independently. Use `single-board` only when that endpoint exposes one image input. Forward only verifier-produced carriers and the reviewed effective prompt.

## Stop conditions

Stop before packaging when deterministic rasterization, Visual preflight, target media validation, visual authority, plan resolution, or carrier verification fails. Do not reconstruct or simplify the committed generation input.
