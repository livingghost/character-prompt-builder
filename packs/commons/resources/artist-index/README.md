# Artist index

`anima2b-artist-index.txt` is a list of artist tags known to one anime-line checkpoint, with their frequency, imported unchanged from a third-party resource. The pack record carries the source and its licence.

It is a style-anchoring aid: an artist tag pulls a tag surface toward that artist's rendering, and the frequency says how strongly the checkpoint knows the tag. Use it to find a rendering family, then describe the look in the prompt's own words (line, colour, finish) so the picture does not depend on the tag; a named artist's style is that artist's, and whether to lean on it is an editorial decision made in the open, not by the tool.
